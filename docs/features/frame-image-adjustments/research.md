# 全帧画质精修与色彩滤镜调研 (Frame Image Adjustments Research)

- **状态**: ready-to-merge
- **分支**: `feature/frame-image-adjustments`
- **日期**: 2026-10-23

## 1. 需求背景

用户制作表情包/动图时，导入的视频素材常常存在画面偏暗、压缩模糊（“电子包浆”）、色彩平淡或需要模糊/色相恶搞等情况。除了已有的 8 种一键风格/变速滤镜（原色、黑白、高反差、复古、反色、2x加速、0.5x慢放、倒放）外，用户希望能够对**所有帧**叠加精细的画质与色彩调节（如增加亮度、提升对比度、画面锐化、饱和度、色相偏移、高斯模糊、暗角等），并在画布上实时预览效果。

## 2. 已确认事实（技术调研）

通过对内置 FFmpeg sidecar（`ffmpeg-aarch64-apple-darwin` v9.0.2）的滤镜列表检测，确认以下全帧图像处理滤镜均原生内置可用，无需额外第三方依赖：

1. **`eq` 滤镜 (`T. eq V->V`)**：
   - 支持参数：
     - `brightness`（范围 `-1.0 .. 1.0`，默认 `0.0`）
     - `contrast`（范围 `-1000.0 .. 1000.0`，默认 `1.0`）
     - `saturation`（范围 `0.0 .. 3.0`，默认 `1.0`）
     - `gamma`（范围 `0.1 .. 10.0`，默认 `1.0`）
   - 性能极高，可在单次遍历中同时完成亮度、对比度与饱和度调节。
2. **`unsharp` 滤镜 (`TS unsharp V->V`)**：
   - 支持对亮度（Luma）与色度（Chroma）通道进行锐化或模糊矩阵卷积：`unsharp=lx:ly:la:cx:cy:ca`。
   - 当 `la > 0`（如 `unsharp=5:5:1.5:5:5:0.0`）时，可显著增强画面边缘清晰度，修复模糊视频画质。
3. **`gblur` 滤镜 (`TS gblur V->V`)**：
   - 高斯模糊滤镜：`gblur=sigma={0.1..20.0}`，适合制作柔焦或背景模糊效果。
4. **`hue` 滤镜 (`T. hue V->V`)**：
   - 色相偏移滤镜：`hue=h={-180..180}`，支持全帧色相旋转。
5. **`vignette` 滤镜 (`T. vignette V->V`)**：
   - 电影级光学暗角滤镜：`vignette=PI/4`，突出画面中心主体。

## 3. 前端实时预览映射方案

- **亮度 / 对比度 / 饱和度 / 色相 / 模糊**：通过 CSS `filter`（`brightness()`, `contrast()`, `saturate()`, `hue-rotate()`, `blur()`）实时作用于画布 `<video>` 与抽帧 `<img>`。
- **锐化 (`sharpen`)**：通过内联 SVG `<filter id="studio-sharpen-filter"><feConvolveMatrix .../></filter>` 动态计算 `3×3` 拉普拉斯锐化卷积核（中心权重 $1 + 4k$，四邻域权重 $-k$），并通过 `url(#studio-sharpen-filter)` 串联进 CSS `filter`，实现零延迟的硬件加速锐化预览。
- **暗角 (`vignette`)**：在画布媒体层叠加径向渐变遮罩层，与 FFmpeg `vignette=PI/4` 视觉对齐。

## 4. 决策总结

1. 在 `📐 画面` 检查器面板中新增 **「✨ 全帧画质与色彩精修」** 卡片，既提供 **一键精修预设**（高清锐化、提亮去暗、浓郁鲜艳、柔焦模糊、赛博冷调），又提供 **6 维滑块 + 暗角开关**（亮度、对比度、饱和度、锐化、模糊、色相、暗角）。
2. 所有调节参数可与原有的「全局画风与变速」滤镜自由叠加组合，并完整支持 GIF / WebP / AVIF / MP4 四种导出格式及草稿/历史记录恢复。
