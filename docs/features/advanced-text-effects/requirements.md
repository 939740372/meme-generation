# 需求说明书：高级文字排版效果 (advanced-text-effects)

- 状态：merged
- Feature slug: advanced-text-effects
- 分支：feature/advanced-text-effects
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 范围与目标

- **核心目标**：
  1. 支持文字自由角度旋转（-180° 到 180°，支持连续滑块与高频快捷角度 `0°`, `-15°`, `+15°`, `-45°`, `+45°`, `90°`）；
  2. 支持文字弧形弯曲排布（弧度 -100 到 100，支持正向拱起彩虹环绕与反向微笑凹弧）；
  3. 支持动感斜体开关（一键切换 12° 动感倾斜排版）；
  4. 支持立体阴影（阴影偏移距离 0~20px，支持自定义阴影颜色）；
  5. 完整兼容多文字图层管理（各个独立图层均可拥有不同的角度、弯曲与阴影）；
  6. 导出格式（GIF / WebP / AVIF / MP4）全覆盖，预览与最终导出高度一致。
- **不在范围**：复杂 3D 挤出立体雕刻、字间距贝塞尔变形（未来作为更高级矢量排版扩展）。

## 2. 用户故事

- 作为一个搞笑短视频创作者，我想在主角脑门上方打上一句弯曲的“前方高能”，环绕头顶拱起，导出成生动短视频表情包。
- 作为一个名梗二次创作用户，我想让文字沿 45° 倾斜贴在画面对角线倾倒的物体上，并添加斜体与黑色阴影，营造出极具冲击力的警示牌效果。
- 作为一个多图层深度用户，我想让主标题水平居中加重阴影，而副标题倾斜 -15° 标红斜体，主副对比鲜明。

## 3. 功能需求

1. **图层文字排版控制面板升级**：
   - 增加 **旋转角度 (Rotation)** 控件：
     - 滑块范围：-180° ~ 180°，步长 1°，默认 0°；
     - 快捷预设按钮：`0°` (重置), `-45°`, `-15°`, `+15°`, `+45°`, `90°`。
   - 增加 **弧形弯曲 (Arc Curvature)** 控件：
     - 滑块范围：-100 ~ 100，步长 5，默认 0 (直线)；
     - 正数表示向上拱起 (Convex)，负数表示向下凹陷 (Concave)。
   - 增加 **动感斜体 (Italic)** 切换按钮：
     - 开关按钮，开启后文字自动呈现动感斜切。
   - 增加 **立体阴影 (Drop Shadow)** 控件：
     - 阴影偏移滑块：0px ~ 20px (步长 1px，默认 0 关闭)；
     - 阴影颜色拾色器：默认 `#000000`。
2. **画布所见即所得交互**：
   - 画布中央选中的文字层实时呈现旋转、斜切、弯曲与阴影效果；
   - 拖拽文字时，以文字几何中心跟随光标，移动流畅无跳变。
3. **Rust 后端转码与滤镜构建**：
   - `TextOverlay` 结构体新增：
     - `rotation: Option<i32>`
     - `arc_radius: Option<i32>`
     - `is_italic: Option<bool>`
     - `shadow_offset: Option<u32>`
     - `shadow_color: Option<String>`
   - `build_filter_graph`：
     - 当无旋转且无弯曲且无斜体：直接应用 `drawtext`（含 `shadowcolor`, `shadowx`, `shadowy`），性能极速；
     - 当有旋转或斜体且无弯曲：使用透明 color 画板，应用 `drawtext`、`shear` 与 `rotate`，并在中心点精确 `overlay`；
     - 当有弧形弯曲：按几何圆弧公式逐字分解排布并计算切向角，叠加到画面对应弧线上。
4. **草稿与队列同步支持**：
   - 自动草稿保存与恢复包含所有高级文字排版属性；
   - 导出队列和历史卡片完整支持所有文字属性的参数重载。

## 4. 验收标准

- 在画布中调整旋转、弯曲、斜体和阴影后，UI 预览实时同步；
- 导出的 GIF / MP4 / WebP / AVIF 经验证准确呈现旋转角度、弧形拱起、斜体与阴影；
- 单元测试覆盖各分支滤镜构建；
- `pnpm build`, `cargo test`, `cargo check --locked`, `git diff --check` 全部绿灯通过。
