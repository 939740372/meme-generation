# 需求调研：全局滤镜与画面调色 (video-filters)

- 状态：merged
- Feature slug: video-filters
- 分支：feature/video-filters
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 背景与痛点

1. **表情包二创核心画风需求**：
   - 全网海量经典 Meme 依赖特定画风渲染情绪：
     - **黑白致郁**：“全剧终”、“小丑竟是我自己”、“emo 了”；
     - **高反差/暗黑特写**：面部戏剧性强化，阴阳怪气；
     - **复古老电影/港片怀旧**：经典影视台词与暖黄色胶片质感；
     - **反色负片**：“震惊我全家”瞬间的鬼畜反相；
     - **速度鬼畜（2x 加速 / 倒放）**：高频魔性点头摇头、倒着吃回去等无厘头效果。
2. **目前创作限制**：
   - 当前画布仅支持原始画面叠加文字与贴图，创作者若想对底色做黑白或反色调色，必须先借助外部剪辑软件处理一遍，大大打断了从原视频直接截取表情包的高效心流。

## 2. 调研结论与技术选型

| 调研项 | 方案对比 | 决策依据 |
|--------|----------|----------|
| 滤镜插入层级 | 在 drawtext / overlay 之前应用 vs 画面整体应用 | **在字幕与贴纸之前应用**：背景视频变黑白/反相/变速，但台词与彩色贴纸仍清晰醒目浮在画面上方，层级清晰符合剪辑规范 |
| 调色滤镜选型 | `hue=s=0`（黑白）、`eq`（高反差）、`colorchannelmixer`（复古）、`negate`（反相） | 原生 FFmpeg filtergraph 链式支持，单次 pass 零额外开销 |
| 速度滤镜选型 | `setpts=0.5*PTS`（2x 加速）、`setpts=2.0*PTS`（0.5x 慢放）、`reverse`（倒放） | 内存占用低，在短截取片段中瞬时完成 |
| 画布所见即所得 | CSS `filter` 与 HTML5 `<video>.playbackRate` | 实时预览无延迟：`grayscale`, `contrast`, `sepia`, `invert` 与倍速播放双向同步 |

## 3. 风险与未知项

- **倒放与 PTS 变速在长视频中的性能**：表情包截取一般在 0.5s~5s 以内，`reverse` 需要在内存中缓冲帧序列。对于短片段，几毫秒内即可完成；对于过长视频，现有截取时间限制（默认推荐短片段）完全安全。
