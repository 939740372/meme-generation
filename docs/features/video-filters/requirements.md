# 需求说明书：全局滤镜与画面调色 (video-filters)

- 状态：ready-to-merge
- Feature slug: video-filters
- 分支：feature/video-filters
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 范围与目标

- 核心目标：为创作者提供开箱即用的经典表情包画面滤镜（黑白、高反差、复古港风、反色负片、2x 鬼畜加速、0.5x 慢放、物理倒放），支持画布实时 CSS 模拟预览与 FFmpeg 真实转码导出；
- 不在范围：暂不引入逐通道曲线调节等专业调色台工具。

## 2. 用户故事

- 作为一个表情包制作者，我想在选中一段影视对白视频后，一键切换为“黑白致郁”画风，配上底部台词，快速生成“小丑竟是我自己”表情包。
- 作为一个鬼畜视频创作者，我想让人物动作加速 2 倍或倒放，生成魔性抽搐的高频表情包。

## 3. 功能需求

1. **滤镜控制选项**：
   - 控制面板第 01 或 02 节提供“画面特效/滤镜”下拉或平铺徽标按钮，支持：
     - `原色 (无特效)`
     - `黑白 (致郁 emo)`
     - `高反差 (戏剧张力)`
     - `复古 (港片怀旧)`
     - `反色 (鬼畜精神污染)`
     - `2x 鬼畜加速`
     - `0.5x 慢动作`
     - `物理倒放`
2. **画布所见即所得 (WYSIWYG)**：
   - 切换调色滤镜时，中央预览播放器实时叠加对应 CSS 滤镜样式；
   - 切换 2x 或 0.5x 速度时，`<video>` 播放速率实时同步联动；
3. **FFmpeg 链式转码处理**：
   - Rust 端 `RenderPlan` 新增 `video_filter: Option<String>`；
   - 在构建 filtergraph 时，于 scale 之后、drawtext/overlay 之前插入对应滤镜子串；
   - 保证输出到 GIF / WebP / AVIF 各格式管道完全兼容；
4. **状态持久化与队列兼容**：
   - 草稿（StudioDraft）与历史记录（ExportRecord）保存并恢复 `videoFilter`；
   - 批量任务队列（QueueItem）冻结并恢复 `videoFilter`。

## 4. 验收标准

- 控制面板切换各滤镜后，画布预览立即展现对应色彩与播放速度；
- 真实导出的动图文件（GIF/WebP/AVIF）中正确包含所选黑白、反色、倒放、加速等效果；
- 文字字幕与贴图不受底图滤镜污染，保持清晰的原色前景；
- 单元测试与端到端 smoke test 验证通过；
- `pnpm build`, `cargo check --locked`, `cargo test` 绿灯通过。
