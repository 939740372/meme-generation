# 需求说明书：自定义背景音乐与音效混流 (bgm-audio-mixing)

- 状态：implementing
- Feature slug: bgm-audio-mixing
- 分支：feature/bgm-audio-mixing
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 范围与目标

- 核心目标：
  1. 为短视频表情导出（MP4 模式）增加背景音乐 (BGM) 与音效 (SFX) 混流能力；
  2. 内置 8 款经典二创无版权高频音效，即选即用；
  3. 支持从本地导入自定义音频文件（MP3 / WAV / M4A / AAC / OGG）；
  4. 支持源片原声音量与 BGM 音量独立平滑调节（0% ~ 200%）；
  5. 混流滤镜保证声画严丝合缝，不拉长视频时长。
- 不在范围：暂不提供多轨道多时间点精确定位轨（后续作为复杂多音轨扩展）。

## 2. 用户故事

- 作为一个搞笑短视频创作者，我想在一段 2 秒的人物瞪眼镜头中，加入内置的“叮~神转折”音效，并保留角色原声对话，导出发微信群。
- 作为一个名场面二创用户，我想在角色说出禁忌台词的瞬间，配上一段“经典消音哔哔”声，并将原声音量调至 30%，生成网梗短视频。
- 作为一个表情包高产创作者，我想导入自己收藏的一段 3 秒魔性 BGM，将无声原片配上音乐直接导出为 MP4。

## 3. 功能需求

1. **音频素材管理与选择**：
   - 底部抽屉新增第五个 Tab：“🎵 音效库”；
   - 内置 8 款经典高频音效卡片（消音哔哔、绝了叮、震撼低音、高能警报、弹簧搞笑、欢呼喝彩、打脸啪、滑稽笑声），点击可试听、一键选用；
   - 控制面板音频节提供“从本地选择音频文件”按钮；
   - 支持随时清除已选音效，恢复为纯原声模式。
2. **音量控制与混流参数**：
   - 当选用了 BGM/音效时，展示两个音量滑块：
     - `源视频音量`: 0% ~ 200% (默认 100%)
     - `音效 / BGM 音量`: 0% ~ 200% (默认 100%)
   - `RenderPlan` 新增 `bgm_overlay: Option<BgmOverlay>`：
     - `path: String`
     - `volume: Option<f64>`（默认 1.0）
     - `orig_volume: Option<f64>`（默认 1.0）
3. **FFmpeg 混流管线处理**：
   - 当仅有原声：保持 `0:a?` 容错输出；
   - 当原声 + BGM：使用 `amix=inputs=2:duration=first:dropout_transition=0` 混合；
   - 当源视频无音频（或原声音量为 0）但有 BGM：仅使用 BGM 流并通过 `atrim=0:duration` 裁剪对齐；
   - 当二者皆无或导出动图（GIF/WebP/AVIF）：自动 `-an` 静音。
4. **历史记录与队列兼容**：
   - 草稿保存与恢复包含 `bgmOverlay`；
   - 批量导出队列完整支持并执行 BGM 混流。

## 4. 验收标准

- 选用内置音效或本地音频后，导出的 MP4 文件正确包含该音效，并通过 `ffprobe` 验证音轨完备；
- 源声音量与音效音量调整按比例生效；
- 源视频原本没有声音时，选用 BGM 导出依然正常完成，不抛出流映射错误；
- 单元测试与端到端 smoke test 验证通过；
- `pnpm build`, `cargo test`, `cargo check --locked` 绿灯通过。
