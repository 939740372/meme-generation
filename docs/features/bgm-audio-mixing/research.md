# 需求调研：自定义背景音乐与音效混流 (bgm-audio-mixing)

- 状态：implementing
- Feature slug: bgm-audio-mixing
- 分支：feature/bgm-audio-mixing
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 背景与痛点

1. **声音是短视频表情二创的爆笑催化剂**：
   - 现有的 `audio-video-export` 实现了源视频原声提取与 MP4 导出，但大量全网爆款表情包二创不仅需要原声，更依赖特定“神级音效”烘托氛围；
   - 经典高频音效场景：
     - **消音哔哔 (Censor Bleep)**：台词爆粗口瞬间的无缝打码；
     - **清脆“叮~”**：人物眼神一亮、妙计心头或神转折瞬间；
     - **震撼低音 (808 Boom)**：前方高能、震撼全家或突发变故；
     - **弹簧搞笑 (Boing)**：人物出糗、滑稽跳跃或头部晃动；
     - **欢呼鼓掌 (Applause)**：反讽点赞、庆祝胜利；
     - **打脸啪 (Slap)**：戏剧性反转打脸。
2. **目前创作者的痛点**：
   - 用户若想为表情包添加一段 BGM 或特定搞笑音效，只能导出无声或原声短视频后，再导入剪映等复杂剪辑软件，导入外部音频轨对齐时间，极大地增加了创作摩擦力；
   - 绝大多数创作者电脑中没有现成的干净透明音效文件。

## 2. 调研结论与技术选型

| 调研项 | 方案对比 | 决策依据 |
|--------|----------|----------|
| 音频混流滤镜 | `amix` vs `amerge` | **选用 `amix=inputs=2:duration=first:dropout_transition=0`**：支持自动将两路音频（原声与 BGM）混合为单一路立体声/单声道输出，且当视频结束时自动截断，不拖长视频总时长 |
| 音量比例独立控制 | `volume=X.X` 独立滤镜 | 源视频音量与 BGM 音量分别提供滑块（0% ~ 200%），原声支持调小让位给 BGM，或调为 0 彻底静音原声只放 BGM |
| 音效素材源 | 仅本地文件选择 vs 内置音效库 + 本地选择 | **双模驱动**：内置 8 款经典二创无版权高频音效（消音哔哔、绝了叮、震撼低音、高能警报、弹簧搞笑、欢呼喝彩、打脸啪等）+ 本地音频文件选择器（`.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`） |
| 音效持续时长与裁切 | `atrim=0:duration` | 音效过长时自动依据视频截取时长 `duration` 进行 `atrim` 裁剪，防止导出视频被背景音乐拉长；如果原声开启变速（如 2x 或 0.5x），原声音频同步挂载 `atempo`，BGM 保持原节奏清晰播放 |
| 预览播放机制 | HTML5 `<audio>` 联动播放 | 画布在预览时联动播放选中的音效/BGM，并同步音量调节，真正做到所听即所得 |

## 3. 风险与未知项

- **源视频无声情况下的混流**：
  - 如果源视频没有音频流，直接对 `[0:a]` 应用 `amix` 会引发 FFmpeg 报错；
  - 应对方案：Rust 端先探测源视频音频流状态；若源视频无音频或用户关闭了原声，则直接将 BGM 轨作为主音频流输出（`[1:a]volume=...`），优雅兼容无声素材。
