# 需求说明书：带音轨的短视频表情导出 (audio-video-export)

- 状态：implementing
- Feature slug: audio-video-export
- 分支：feature/audio-video-export
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 范围与目标

- 核心目标：在导出选项中新增 MP4 格式，支持将截取的视频片段连同原声音频、多层文字字幕、贴图与画面特效一键导出为标准 H.264+AAC MP4 视频；
- 不在范围：暂不提供多音轨混音器或外部背景音乐导入（后续版本扩展）。

## 2. 用户故事

- 作为一个表情包制作者，我从一部经典电影中截取了 3 秒爆笑台词片段，我想保留演员的嘶吼原声和自己加的大字报台词，导出成可直接发微信对话框的 MP4 短视频。
- 作为一个鬼畜制作者，我想在开启 2x 鬼畜加速或倒放时，声音也同步变成 2x 尖锐快嘴或魔性倒放音效，导出声画合一的短视频。
- 作为一个批量处理用户，我想将选中的多个带台词镜头加入队列，统一导出为带音频的 MP4 视频合集。

## 3. 功能需求

1. **导出格式增加 MP4 选项**：
   - 格式选择器支持：`GIF`、`WebP`、`AVIF`、`MP4 (有声微视频)`；
   - 切换到 MP4 时，主导出按钮文案自动更新为 `导出 MP4 ↗`；
2. **音频控制开关**：
   - 控制面板导出设置中提供“保留原声音频”开关（`includeAudio: boolean`，默认 `true`）；
   - 当格式为 MP4 且开启保留原声时，FFmpeg 自动抽取并编码源视频音轨；
   - 当格式为 MP4 且关闭保留原声时，使用 `-an` 导出纯静音 MP4 视频；
   - 当格式为 GIF/WebP/AVIF 时，保持静音导出；
3. **音频容错与变速滤镜联动**：
   - FFmpeg 映射参数采用 `-map 0:v -map 0:a?`，源视频没有音轨时自动降级输出无声 MP4，任务不报错；
   - 当激活速度滤镜时，音频自动挂载对应音频滤镜：
     - `speed2x` -> `-af atempo=2.0`
     - `slowmo` -> `-af atempo=0.5`
     - `reverse` -> `-af areverse`
4. **历史记录与队列兼容**：
   - 历史记录卡片支持 MP4 徽标展示、视频原声与画面预览、在访达中定位；
   - 批量任务队列（QueueItem）完整支持 `"mp4"` 格式与 `includeAudio` 参数，按规则生成 `.mp4` 后缀；
   - 草稿保存与恢复包含 `includeAudio` 设置。

## 4. 验收标准

- 导出格式切换为 MP4 后，能成功导出合规的 `.mp4` 文件；
- 导出的 MP4 文件通过 `ffprobe` 验证包含 `h264` 视频流和 `aac` 音频流；
- 导出的 MP4 在包含文字、贴图、特效的同时声画同步；
- 输入源为纯静音/无音频流视频时，导出 MP4 正常完成且不抛出流映射错误；
- 单元测试与端到端 smoke test 验证通过；
- `pnpm build`, `cargo test`, `cargo check --locked` 绿灯通过。
