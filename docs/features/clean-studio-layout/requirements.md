# 需求规范：极简创作工作台布局重构 (clean-studio-layout)

- 状态：merged
- Feature slug：clean-studio-layout
- 分支：feature/clean-studio-layout
- 负责人：Meme Studio Team
- 日期：2026-10-22

## 1. 业务范围

对 Meme Studio 桌面端页面布局进行结构性减法与分区重构，在不删减任何已有业务能力的前提下，消除界面中的重复元素与纵向堆砌感，建立高颜值、低认知负荷的极简创作工作台。

## 2. 用户故事

- 作为用户，当我打开软件时，我希望看到宽敞干净的预览画布和清晰的功能分区，而不是满屏密密麻麻的输入框、滑块和重复的状态标签；
- 作为用户，当我想修改文字、调整画面裁切、添加贴纸音效或更改导出格式时，我可以通过右侧清晰的分类 Tab 快速切换到对应面板，面板内不会混杂其他无关模块的参数；
- 作为用户，当我在画布上直接点击文字、贴纸或裁切框时，右侧属性面板能自动切换到对应的功能分类，让所见即所得的操作更加顺畅；
- 作为用户，我依然可以随时从顶部工具栏一键唤出模板库、贴纸库、音效库、批量队列和历史记录抽屉。

## 3. 功能需求

1. **一体化极简顶栏 (FR-01)**：
   - 移除原有的左侧常驻导航栏（`studio-sidebar`）和双层标题栏（`topbar` + `page-intro`）；
   - 建立单行顶栏：左侧展示品牌标志（表情工坊）、当前视频文件胶囊（显示文件名、分辨率、帧率及快速「更换视频」入口）；
   - 右侧集中提供抽屉快捷入口（`模板库`、`贴纸库`、`音效库`、`队列`、`历史`）、`重置` 按钮及单一运行环境指示灯。
2. **沉浸式画布与一体化时间轴栏 (FR-02)**：
   - 左侧主舞台最大化展示视频/抽帧预览与交互图层（文字、贴纸、九宫格裁切框）；
   - 空状态时提供大尺寸居中导入引导按钮；
   - 画布下方整合为单一的「播控与时间裁切栏」：包含播放/暂停、静音切换、可视化双滑块时间轴，以及内联的起止时间精确输入框（精确到 0.1s）和选中时长徽章。
3. **右侧四分栏属性检查器 (FR-03)**：
   - 右侧面板顶部设置四分栏分段导航（Segmented Tabs）：
     - **Tab 1 `画面`**：画面裁切开关、6 项比例快捷按钮、按需展开的精确坐标（X/Y/W/H），以及 8 项全局画风与变速滤镜；
     - **Tab 2 `文字`**：文字叠加开关、模板库/存为模板入口、多图层切换条（T1~T4）、台词输入与基础样式（字号、文字色、描边、底框）；将「高级效果（旋转/弧形/斜体/阴影）」与「精确坐标（X/Y）」收纳为可折叠子面板；
     - **Tab 3 `贴纸·声音`**：透明贴纸开关、贴纸库/本地 PNG 选择、快捷缩放（60%/100%/150%）；以及视频原声开关/音量、BGM 音效库/本地音频混流与音量调节（选用音效时自动联动或提示 MP4 格式）；
     - **Tab 4 `导出`**：输出格式选择（GIF / WebP / AVIF / MP4）、5 档场景预设（微信表情/大表情/高清动图/轻量秒发/自定义）、宽度与 FPS 设置、输出路径选择及 GPU 硬件加速开关。
   - 每个 Tab 标题支持小型状态圆点提示（例如已开启文字、裁切、滤镜或贴纸时显示激活点，让用户一眼知晓哪些效果处于启用状态）。
4. **画布与检查器智能联动 (FR-04)**：
   - 在画布中按下/拖拽文字图层时，右侧自动切换至 `文字` Tab 并选中该图层；
   - 在画布中按下/拖拽/缩放贴纸时，右侧自动切换至 `贴纸·声音` Tab；
   - 在画布中按下/拖拽/缩放裁切框时，右侧自动切换至 `画面` Tab。
5. **精简底部导出栏与全功能抽屉兼容 (FR-05)**：
   - 底部导出栏左侧展示当前任务状态与输出规格摘要（如 `GIF · 320px · 12FPS`），右侧放置「加入队列」与主「导出」按钮（完成后展示「访达定位」与「复制文件」）；
   - 底部弹出抽屉（历史、模板、贴纸、音效、队列）及存为模板弹窗功能完整保留，视觉与新布局统一。

## 4. 非功能需求

1. **零功能退化 (NFR-01)**：所有已有参数绑定、快捷键（空格播放、Esc 关抽屉）、草稿恢复与 FFmpeg 导出管线 100% 保持原样工作；
2. **无嵌套滚动混乱 (NFR-02)**：主窗口保持 `100vh` 固定一屏工作台体验，右侧单个 Tab 内部内容精简紧凑，绝大多数场景无需滚动即可操作全部核心项；
3. **响应式与视觉一致性 (NFR-03)**：深色专业工作室配色（曜石黑底色 + 荧光青柠强调色），控件间距、圆角与字体层级统一。

## 5. 验收标准

- [x] 页面不再出现左侧冗余栏和三处重复的“桌面端”标识；
- [x] 画布下方时间轴与播放控制合二为一，既能拖拽滑块又能直接微调开始/结束秒数；
- [x] 右侧属性面板分为「画面」「文字」「贴纸·音效」「导出」4 个独立 Tab，切换流畅且带启用状态指示点；
- [x] 点击画布上的文字、贴纸、裁切框能自动切换到对应属性 Tab；
- [x] `pnpm build`、`cargo check`、`cargo test` 及已有自动化测试脚本全部通过。
