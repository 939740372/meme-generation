# 需求调研：极简创作工作台布局重构 (clean-studio-layout)

- 状态：merged
- Feature slug：clean-studio-layout
- 分支：feature/clean-studio-layout
- 负责人：Meme Studio Team
- 日期：2026-10-22

## 1. 背景和问题

随着 P1、P2、P3 阶段十余项功能（时间轴裁切、多文字图层、高级文字变形、透明贴纸库、全局滤镜、MP4 声画混流、内置音效库、多格式导出、硬件加速、批量队列、模板与历史记录）的陆续合入，当前单页工作区出现了明显的**功能堆叠与视觉过载**问题：

1. **外围框架冗余**：
   - 左侧固定占据 `198px` 宽度的侧边栏（`studio-sidebar`），实际仅放置了“动图制作”静态锚点、“模板库”按钮和 2 条微小历史卡片；
   - 主区顶部同时存在 `topbar`（52px）和 `page-intro`（52px 巨型 `<h1>制作 GIF</h1>`），且“桌面端就绪”状态在左侧栏底部、顶栏、标题栏右侧**重复出现了 3 次**，严重挤压了核心画布的可用面积。
2. **预览区底部信息重复**：
   - 画布下方依次堆叠了 `preview-bottom-toolbar`（播放按钮 + 时间显示）、`timeline-panel`（时间轴 + 第二次时间显示）、`media-summary`（文件信息 + 第三次时长显示），而右侧面板 `01 时间` 又第四次展示了开始/结束秒数输入框。
3. **右侧参数面板“大杂烩”式纵向堆砌**：
   - 右侧 `controls-panel` 将 `01 时间`、`02 输出预设 + 宽度/FPS + 画面裁切 + 8种画风滤镜`、`03 叠加（文字图层 + 字号颜色描边底框 + 旋转/弧形/斜体/阴影 + 贴纸图案 + 缩放）`、`04 格式与保存（4种格式 + 原声音量 + BGM音效混流 + 输出路径 + 硬件加速）` 全部平铺在同一个滚动容器中；
   - 用户只想改一句台词或调一下裁切时，视线被迫穿过数十个滑块、数字框、色板和胶囊按钮，认知负荷极高。

用户明确提出：**“帮我修改下这个项目的页面布局，不要那么多功能参杂在一起，稍微做的简洁点，按你的思路设计。”**

## 2. 设计思路与竞品参考

参考现代轻量级桌面创意工具（如 **Screen Studio**、**CleanShot X**、**CapCut 桌面极简模式**、**Linear**）：
- **去侧边栏化（No Redundant Sidebar）**：单一核心工作流工具不需要常驻左侧导航栏。将品牌标识、当前媒体信息、素材/任务抽屉入口（模板、贴纸、音效、队列、历史）整合进**单行 48px 极简顶栏（Unified Top Header）**，释放近 200px 水平宽度与 60px 垂直高度给中央画布。
- **画布与时间轴一体化（Integrated Stage & Timeline）**：将播放控制、静音切换、精确起止秒数微调输入与可视化拖拽时间轴合并为画布正下方的**一体化播控时间栏**，彻底消除 4 处重复的时间展示。
- **右侧属性面板模块化分栏（Tabbed Inspector）**：
  告别全部功能纵向混排，按创作直觉拆分为 **4 个职责单一的 Tab 面板**：
  1. **📐 画面（裁切 & 滤镜）**：专注画面构图裁切（含快捷比例与画布九宫格联动）和全局画风/变速特效；
  2. **🔤 文字（台词 & 样式）**：专注多文字图层编辑、核心样式（字号/颜色/描边/底框），并将低频参数（旋转/弧形/斜体/阴影、精确 X/Y 坐标）收纳进**按需展开的折叠面板**；
  3. **🎨 贴纸与音效（素材叠加）**：专注透明贴纸叠加与视频原声/BGM 音效混流；
  4. **🚀 导出（格式 & 预设）**：专注导出格式（GIF/WebP/AVIF/MP4）、尺寸帧率预设、输出路径与 GPU 硬件加速。
- **画布点击智能联动（Contextual Tab Switching）**：在画布上直接点击/拖拽文字图层自动切到「🔤 文字」Tab，点击贴纸自动切到「🎨 贴纸与音效」Tab，拖拽裁切框自动切到「📐 画面」Tab。

## 3. 已确认事实

- 所有后端 Tauri 命令、FFmpeg 渲染管线、草稿持久化（`StudioDraft`）、历史记录与批量队列逻辑均无需改动，保持 100% 兼容；
- 重构聚焦于 `src/App.vue` 模板结构与交互状态组织，以及 `src/styles.css` 布局样式体系。

## 4. 调研结论和决策

| 决策项 | 方案选择 | 理由 |
| --- | --- | --- |
| 宏观布局结构 | **三段式极简工作台**：顶栏 (Header) + 主工作区 (左画布时间轴 + 右分栏检查器) + 底栏 (Export Bar) | 消除冗余侧边栏与双层顶栏，画布视觉占比提升 30% 以上 |
| 右侧控制面板 | **4-Tab 模块化检查器**（画面 / 文字 / 贴纸音效 / 导出设置） | 每次只呈现单一维度的控制项，彻底解决“多功能参杂在一起”的痛点 |
| 复杂参数降噪 | **渐进式披露（Progressive Disclosure）**：高级文字变形、精确坐标微调默认折叠，开启时高亮提示 | 保证常用操作一步直达，低频参数不干扰视线 |
| 时间控制收敛 | 合并至画布下方的一体化播控时间轴栏（支持拖拽滑块 + 内联数字微调） | 消除画布与右侧面板重复的时间输入区域 |
