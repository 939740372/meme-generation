# 需求规范：可视化矩形裁切框与画布交互

- 状态：designed
- Feature slug: visual-crop-box
- 分支：feature/visual-crop-box
- 负责人：待定
- 日期：2026-10-22

## 1. 范围与目标

### 1.1 范围内 (In Scope)
1. **裁切开关联动**：
   - 当勾选「裁切」时，中央画布立即激活可视化裁切层；
   - 取消勾选「裁切」时，裁切层平滑隐藏，保留当前参数供二次开启使用。
2. **暗色半透明遮罩**：
   - 裁切框外部区域覆盖 `rgba(0, 0, 0, 0.6)` 半透明暗色遮罩；
   - 裁切框内部区域完全透明，高亮展示保留的画面。
3. **九宫格与 8 向调节手柄**：
   - 裁切框内部渲染经典三分构图九宫格（Rule-of-Thirds Grid）；
   - 包含 4 个角手柄（NW, NE, SW, SE）与 4 个边缘手柄（N, S, W, E）；
   - 手柄支持高对比度高亮悬浮反馈与专业方向光标。
4. **画布拖拽交互与坐标约束**：
   - 拖拽裁切框内部：整体平移选区，并限制在 $[0, \text{Width} - W]$ 与 $[0, \text{Height} - H]$ 范围内；
   - 拖拽任意手柄：自由拉伸或缩小选区尺寸，设置最小尺寸保护（例如不小于 24×24 像素），防止翻转或退化为 0；
   - 拖拽与缩放过程中，浮动显示当前真实视频坐标与尺寸 Pill（如 `W: 480 × H: 270 (X: 120, Y: 80)`）。
5. **双向响应式联动**：
   - 画布拖拽 -> 实时同步至控制面板中 `crop.x`, `crop.y`, `crop.width`, `crop.height` 数值；
   - 控制面板输入 -> 实时驱动画布裁切矩形框缩放与重定位。
6. **快捷构图操作辅助**：
   - 在控制面板裁切区提供「居中对齐」、「重置铺满」、「1:1 正方形」快捷按钮。

### 1.2 范围外 (Out of Scope)
- 任意多边形或套索裁切；
- 画布内任意角度旋转裁切；
- 独立于视频的非矩形裁剪。

## 2. 用户故事与验收标准

### 用户故事 1：可视化构图调整
- **作为** 一名表情包制作者，
- **我想要** 在视频预览区域直接拖拽选区框圈出想要保留的画面，
- **以便于** 我直观地构图并裁剪掉多余背景。
- **验收标准**：
  1. 勾选「裁切」后，画布中央立即出现可拖拽选区框与暗色遮罩；
  2. 鼠标按住选区框中心可任意移动位置，边缘被牢牢限制在视频画面内部；
  3. 鼠标拖动 8 个手柄可从各个方向拉伸或收缩选区。

### 用户故事 2：双向数据同步
- **作为** 一名追求精确像素的用户，
- **我想要** 画布交互与右侧面板输入框保持绝对数值同步，
- **以便于** 我既能鼠标粗调，也能键盘微调。
- **验收标准**：
  1. 画布拖拽时，面板 X/Y/W/H 输入框数值实时以四舍五入整数更新；
  2. 在面板手动修改任意数值（如将 W 从 320 改为 400），画布上的选框尺寸立即按比例重绘。

### 用户故事 3：快捷构图按钮
- **作为** 一名追求效率的用户，
- **我想要** 一键设置 1:1 正方形或让裁切框居中，
- **以便于** 迅速制作规整的头像或表情包。
- **验收标准**：
  1. 点击「居中」，当前宽高的选框自动居中对齐源视频；
  2. 点击「1:1」，选框自动调整为正方形并保持居中；
  3. 点击「铺满」，选框恢复至源视频的完整全画幅。

## 3. 非功能需求

1. **流畅度**：拖拽与拉伸过程中无卡顿、无跳变，达到 60 FPS 流畅响应。
2. **视口稳定性**：在 `1280 × 820` 固定窗口下，画布遮罩与控制手柄不得产生任何溢出或页面级滚动条。
3. **层级协调性**：裁切框、文字图层（`useText`）、贴图图层（`useImage`）相互独立响应 PointerEvents，互不干扰，层级清晰。
