# 需求规范：最近导出历史与快捷操作

- 状态：designed
- Feature slug: export-history
- 分支：feature/export-history
- 负责人：待定
- 日期：2026-10-22

## 1. 范围与目标

### 1.1 范围内 (In Scope)
1. **导出完成联动**：每次 GIF 导出成功（`render_completed` 事件）后，自动向本地历史队列头部写入一条记录。
2. **轻量持久化**：
   - 存储在 `localStorage`，上限保留 8~10 条（先进先出/LRU）；
   - 单条记录包含：唯一 `id`、文件名 `fileName`、绝对路径 `filePath`、大小 `outputBytes`、导出时间戳 `timestamp`、缩略图 `previewUrl`（按需异步加载）、以及当时使用的完整渲染参数 `plan: RenderPlan`。
3. **侧边栏“最近导出”卡片**：
   - 在侧边栏主导航下方（品牌与底部系统卡片之间）增加「最近导出」区域；
   - 展示最新 1~2 张表情包微缩图、文件名、大小及快捷操作按钮（在访达中显示、复制、载入参数）；
   - 提供「查看全部 (N)」按钮以展开底部历史抽屉。
4. **底部历史抽屉（Collapsible Drawer）**：
   - 提供滑出式浮层抽屉，展示全部历史条目；
   - 支持单条删除和一键清空全部历史；
   - 支持点击遮罩或关闭按钮快速收起。
5. **三大快捷操作**：
   - **在访达/资源管理器中打开**：调用 Tauri opener `revealItemInDir` 原生定位并高亮文件；
   - **复制文件**：优先将真实文件挂载到系统剪贴板（macOS 原生能力），同时将文件路径复制到系统剪贴板，并弹出全局 Toast 提示；
   - **载入此历史参数**：一键将历史记录中的视频路径、裁切时间、输出参数、文字/贴图叠加等配置回填至工作区编辑器。
6. **导出成功栏直达快捷操作**：
   - 底部导出状态条在导出成功后，除显示大小外，直接提供「在访达中显示」、「复制文件」与「历史」快捷入口。

### 1.2 范围外 (Out of Scope)
- 历史记录的云端多端同步；
- 已导出 GIF 的重命名与直接物理删除（避免越权误删用户重要资产）；
- 原始视频源文件的本地自动备份。

## 2. 用户故事与验收标准

### 用户故事 1：即时在访达中定位
- **作为** 一名表情包创作者，
- **我想要** 导出完成后立刻在访达或资源管理器中看到高亮选中的 GIF 文件，
- **以便于** 我可以拖拽给其他应用或整理到指定文件夹。
- **验收标准**：
  1. 点击「在访达中打开」或「定位」按钮，直接唤起 Finder / Explorer 并高亮选中该 GIF；
  2. 若文件已被移动或不存在，弹出友好错误提示。

### 用户故事 2：一键复制文件秒发微信
- **作为** 一名微信重度用户，
- **我想要** 在应用内一键复制导出的 GIF 文件，
- **以便于** 我在微信聊天窗口直接 `Cmd+V` 粘贴即可发送动图。
- **验收标准**：
  1. 点击「复制文件」，系统提示「已复制文件，可直接在微信中粘贴」；
  2. 在微信或 Slack 窗口按 `Cmd+V`，能正确识别并粘贴动图文件；若系统环境不支持，也能正确粘贴文件绝对路径。

### 用户故事 3：最近导出历史与缩略图浏览
- **作为** 一名频繁创作的用户，
- **我想要** 在侧边栏和抽屉中查看最近制作的 5~10 张表情包及缩略图与大小，
- **以便于** 我对比不同压缩参数下的画质与体积表现。
- **验收标准**：
  1. 历史列表按时间倒序排列，最新导出的排在最前；
  2. 列表中卡片显示 GIF 真实预览、文件名、文件体积（格式化为 KB / MB）与相对时间（例如“刚刚”、“3分钟前”）；
  3. 支持单条从列表中移除或一键清空。

### 用户故事 4：参数无缝回溯重用
- **作为** 一名需要微调字句的创作者，
- **我想要** 从历史记录中一键载入上次的参数，
- **以便于** 我无需重新配置分辨率、帧率、裁切时间与字体颜色即可快速生成新变体。
- **验收标准**：
  1. 点击「载入参数」，工作区的视频输入、起止时间轴、预设尺寸、文字叠加及贴图配置全部恢复；
  2. 提示「已恢复该表情的历史制作参数」。

## 3. 非功能需求

1. **视口稳定性**：在 `1280 × 820` 固定窗口下，新增的侧边栏卡片与底部抽屉绝对不得引发主视口产生全局或局部异常滚动条。
2. **轻量与响应性**：读取历史列表与缩略图加载耗时 < 50ms，历史数据更新即时保存至 `localStorage`。
3. **健壮性**：即使底层文件被用户外部删除，界面操作均有优雅错误捕获与提示，应用不崩溃。
