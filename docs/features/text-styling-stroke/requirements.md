# 需求规范：文字描边与字幕底色条增强

- 状态：ready-to-merge
- Feature slug: text-styling-stroke
- 分支：feature/text-styling-stroke
- 负责人：待定
- 日期：2026-10-22

## 1. 范围与目标

### 1.1 范围内 (In Scope)
1. **文字描边控制 (Text Stroke)**：
   - 描边粗细：支持 0~10 像素调节（0 表示无描边，经典 Meme 建议 2~3px）；
   - 描边颜色：支持 Hex 颜色选择器（默认 `#000000` 黑色）。
2. **文字背景底框控制 (Text Background Box)**：
   - 底框开关：可勾选开启/关闭底框（默认关闭或按需开启）；
   - 底框颜色：支持 Hex 颜色选择器（默认 `#000000`）；
   - 底框不透明度：支持 0.1~1.0（10%~100%）滑块微调（默认 0.6 即 60% 透明度）。
3. **中央画布所见即所得实时渲染**：
   - 在中央预览画布中，文字实时呈现设置的描边与半透明底框；
   - 缩放计算：描边宽度自适应视频与视口缩放比率，保证在小视口预览时视觉比例协调。
4. **FFmpeg 转码底层结构化联动**：
   - Rust 端解析 `strokeWidth`、`strokeColor`、`useBox`、`boxColor`、`boxOpacity`；
   - 结构化构建 `borderw`、`bordercolor`、`box`、`boxcolor`，彻底移除旧版硬编码底框。
5. **历史参数回溯兼容**：
   - 「载入历史参数」自动回填文字的新增样式属性；
   - 旧历史记录缺少新字段时自动提供安全优雅默认值。

### 1.2 范围外 (Out of Scope)
- 多重渐变文字与复杂阴影滤镜；
- 富文本（同一行文字不同字号或颜色）；
- 文字随时间关键帧动画。

## 2. 用户故事与验收标准

### 用户故事 1：高对比度黑边白字
- **作为** 一名表情包创作者，
- **我想要** 给白色文字加上 2 像素黑色描边，
- **以便于** 在高光、白色或杂乱背景画面中，文字依然清晰醒目。
- **验收标准**：
  1. 开启描边宽度 > 0 时，画布上的文字边缘出现平滑描边；
  2. 导出 GIF 后，FFmpeg 生成的动图文字带黑边，与画布预览效果一致。

### 用户故事 2：半透明影视台词条
- **作为** 一名影视剧截图创作者，
- **我想要** 给台词加上 60% 透明度的深黑底色条，
- **以便于** 打造沉浸式的电影台词字幕效果。
- **验收标准**：
  1. 勾选「底框」开关，文字下方出现半透明矩形衬底；
  2. 拖拽透明度滑块，底框透光率即时改变；
  3. 导出的 GIF 与设定的底色及透明度一致。

### 用户故事 3：无底框纯净字幕
- **作为** 一名极简风格创作者，
- **我想要** 关闭文字底框，只保留字形，
- **以便于** 不遮挡背景中精美的人物面孔。
- **验收标准**：
  1. 取消勾选底框后，文字背景变为完全透明；
  2. 导出的 GIF 没有多余黑框。

## 3. 非功能需求

1. **视口稳定性**：在 `1280 × 820` 固定窗口下，文字控制面板紧凑排布，不得引发任何视口级滚动条。
2. **前后向兼容**：历史记录或老版本 Plan 缺失描边字段时，默认使用零描边无底框，杜绝运行时报错。
3. **代码健康度**：`pnpm build` 与 `cargo check/test` 必须无报错无警告。
