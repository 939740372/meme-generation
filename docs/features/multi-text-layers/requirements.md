# 需求说明书：多文字图层支持

- 状态：ready-to-merge
- Feature slug: multi-text-layers
- 分支：feature/multi-text-layers
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 特性概述

本特性为 Meme Studio 引入**多文字图层系统**。创作者可在同一个表情包中添加 2~4 个彼此独立的文字图层，各自拥有独立的文案、字号、前景色、描边粗细与颜色、字幕底色条与透明度以及在画面中的自由坐标。中央预览画布支持对多个图层直接点击选中、高亮指示和拖拽排版，底层通过 FFmpeg 链式滤镜高保真导出。

## 2. 用户故事

- **US-1 添加与切换图层**：作为创作者，在“文字叠加”区域我可以看到图层标签栏（默认“文字 1”），点击“＋ 添加图层”可以新增“文字 2”，并在多个图层间自由切换以配置不同样式。
- **US-2 画布点击与独立拖拽**：作为创作者，在中央画布中我可以直接用鼠标点击“文字 1”或“文字 2”，被选中的文字展示高亮指示轮廓，按住即可直接拖拽到画面任何位置。
- **US-3 显隐切换与删除**：作为创作者，我可以点击某个图层上的眼睛图标临时隐藏该文字进行导出对比，也可以删除不再需要的文字图层（至少保留 1 个图层）。
- **US-4 高保真多行渲染导出**：作为创作者，导出为 GIF 或 WebP 动图时，所有开启且可见的文字图层均完整、清晰地呈现在最终文件中。
- **US-5 草稿与模板协同**：作为创作者，当前配置的多个文字图层自动暂存在本地草稿中，重启后完整还原；选择排版模板时可一键套用至当前选中的图层。

## 3. 功能需求清单

### 3.1 前端图层管理与控制
- **FR-1 图层标签栏**：
  在控制面板“文字”设置内提供紧凑的水平标签栏：
  - 显示各图层名称（`文字 1`, `文字 2`, ...）；
  - 高亮当前处于选中编辑状态的图层；
  - 数量上限为 4 个，达到上限时“＋”按钮自动禁用；
  - 每个图层标签提供显隐开关（眼睛图标）和删除按钮（当总数 > 1 时可用）。
- **FR-2 独立样式配置**：
  每个图层具备完全独立的参数：
  - 内容（`text`）
  - 坐标（`x`, `y`）
  - 字号（`size` 8~192px）
  - 颜色（`color` 16进制）
  - 描边（`strokeWidth` 0~12px, `strokeColor`）
  - 底框（`useBox` 开关, `boxColor`, `boxOpacity` 0.1~1.0）
- **FR-3 画布交互增强**：
  - 画布上遍历渲染所有 `visible === true` 的文字图层；
  - 鼠标在某个文字上移动时显示 pointer 抓手手势，点击即切换该图层为活跃编辑图层；
  - 活跃图层展示微光虚线轮廓与实时拖拽坐标小药丸；
  - 拖拽仅更新当前选中文字的独立 `x`, `y` 坐标。

### 3.2 Rust / 后端滤镜扩展
- **FR-4 数据结构升级与兼容**：
  - `RenderPlan` 新增 `text_layers: Option<Vec<TextOverlay>>`；
  - 辅助方法 `active_text_layers(&self) -> Vec<&TextOverlay>` 统一归一化单图层与多图层数据。
- **FR-5 链式滤镜图构建**：
  - `build_filter_graph` 遍历所有有效文字图层，依序追加 `drawtext` 滤镜，以逗号 `,` 分隔；
  - 每一个图层保留字体检测、特殊符号转义、颜色转换、描边与底框逻辑。
- **FR-6 输入校验增强**：
  - 校验图层数量不超过 6 个；
  - 校验每一个图层的字符安全性、非空与合法范围。

### 3.3 模板与草稿集成
- **FR-7 自动草稿持久化**：
  - `StudioDraft` 支持保存 `textLayers` 数组与 `activeTextLayerId`；
  - 冷启动恢复时完整恢复全部图层。
- **FR-8 模板套用目标**：
  - 点击套用模板时，将模板样式直接赋值给当前活跃图层（不影响其他图层的排版）。

## 4. 非功能需求

- **NFR-1 视口无溢出**：新增图层切换控制栏高度控制在 28px 以内，严格保证 1280x820 视口零多余滚动条；
- **NFR-2 性能保证**：链式追加 `drawtext`，多图层相比单图层渲染时间增加不超过 5%。

## 5. 验收标准 (Acceptance Criteria)

1. **AC-1**：用户可成功添加至最多 4 个文字图层，并分别配置不同的内容、字号、颜色和描边。
2. **AC-2**：中央预览画布中，点击任一文字即可选中，拖拽可自由改变该文字位置且其他文字位置保持不动。
3. **AC-3**：点击眼睛图标隐藏某一图层后，画布与导出的动图中均不出现该文字。
4. **AC-4**：成功导出包含两个或多个独立文字的 GIF 与 WebP，两段文字清晰完整呈现。
5. **AC-5**：全量代码通过 `pnpm build`、`cargo check`、`cargo test` 与 `git diff --check`。
