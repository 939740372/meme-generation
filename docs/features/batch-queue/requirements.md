# 需求说明书：批量处理与导出任务队列 (batch-queue)

- 状态：ready-to-merge
- Feature slug: batch-queue
- 分支：feature/batch-queue
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 特性概述

为 Meme Studio 增加“加入导出队列”与“批量处理任务队列”能力。创作者在排版完当前片段后，可将其作为独立快照一键推入导出队列，随后立即开始剪辑下一个名场面；在队列抽屉中可查看全部排队中、处理中、已完成的任务进度，并可一键启动顺序批量导出、暂停队列或清空已完成项。

## 2. 用户故事

1. **连贯创作心流**：作为博主，我导入一部 5 分钟的电影视频，先选出第 1 个名场面加了墨镜，点击“加入队列”；接着拖动时间轴选出第 2 个名场面加上吐槽台词，点击“加入队列”；总共加了 5 个片段，全程不需要停下来等转码；
2. **一键集中渲染**：片段全部选好后，我点击“🚀 开始批量导出”，应用自动按顺序依次转码导出，进度实时更新，我可以去喝杯水；
3. **清晰进度与防覆盖**：我在队列抽屉中看到 5 个任务卡片依次打钩，每个文件都有唯一的命名，完成后能一键在访达中打开，也可以单独重试失败项。

## 3. 功能需求 (FR)

- **FR-1 加入导出队列 (Add to Queue)**：
  - 底部操作栏新增“＋ 加入队列”按钮；
  - 点击时对当前工作区参数（视频源、起止时间、裁切、多文字图层、贴纸、格式、质量）生成完整的独立不可变快照（`RenderPlan`）；
  - 自动分配唯一的任务 ID 与防冲突输出文件名（例如 `video_01.2s-03.5s.gif`）；
  - 加入成功后弹出 Toast 提示（如“已加入队列，当前共 3 个任务”），工作区不重置，用户可无缝微调参数切下一个片段。
- **FR-2 队列抽屉面板 (Queue Drawer)**：
  - 底部抽屉增加 Tab：“📋 导出队列 (N)”；
  - 顶部操作栏提供：
    1. “🚀 开始批量处理” / “⏸ 暂停队列”切换按钮；
    2. “🗑 清空已完成” / “清空全部”；
    3. 队列摘要统计（例如：待处理 3 / 进行中 1 / 已完成 2）。
  - 任务列表展示卡片：
    - 状态标签（排队中 `pending`、渲染中 `rendering`、已完成 `completed`、失败 `failed`）；
    - 视频名称、起止时间范围（例如 `01.20s ~ 03.50s`）、输出格式、字号/图层概要；
    - 独立渲染进度条与阶段信息；
    - 操作按钮：单个移除（未开始时）、在访达中定位（完成时）、单个重试（失败时）。
- **FR-3 调度器顺序执行 (Sequential Runner)**：
  - 严格保持单任务 FIFO 串行执行，避免多进程抢占 CPU；
  - 运行中的任务复用现有的 Tauri `render_gif` 流水线（支持细粒度进度回调、失败归一化、取消控制）；
  - 单任务成功时自动写入“最近历史记录”；
  - 单任务失败时不崩溃退出，记录错误原因并自动拉取下一条任务。
- **FR-4 底部主操作区状态联动**：
  - 保留单个直接“立即导出”按钮（适合单图场景）；
  - 当队列中有未完成任务时，操作区直观展示“🚀 批量导出 (N)”快捷操作；
  - 正在批量处理时，支持点击“暂停队列”或“取消当前”。

## 4. 非功能需求 (NFR)

- **稳定性**：队列中单项转码失败不应导致进程崩溃或队列卡死；
- **响应性**：加入队列操作耗时 < 10ms，零卡顿；
- **内存安全**：队列卡片只存储元数据与必要参数，避免内存泄露；
- **跨平台一致性**：自动生成的文件名兼容 macOS / Windows 文件名非法字符规则。

## 5. 验收标准 (DoD)

1. 用户点击“＋ 加入队列”能够将不同时间段/文字样式的片段加入队列，队列计数正确递增；
2. 连续加入 3 个片段，点击“开始批量导出”，3 个任务依次自动完成转码，输出 3 个独立文件且内容与对应片段一致；
3. 队列任务成功后自动出现在“历史记录”中，并可在访达中一键定位；
4. 队列中若有失败任务，展示错误原因并能点击“重试”，同时不阻塞后续任务；
5. `pnpm build`、`cargo check --locked`、`cargo test`、`git diff --check` 全部通过。
