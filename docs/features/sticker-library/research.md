# 需求调研：内置透明表情贴纸库 (sticker-library)

- 状态：ready-to-merge
- Feature slug: sticker-library
- 分支：feature/sticker-library
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 背景与核心痛点

当前 Meme Studio 虽然支持通过 FFmpeg `overlay` 滤镜叠加 PNG 图片，但用户面临严重的使用阻碍：
1. **本地无现成透明素材**：绝大多数普通创作者电脑中并没有现成带 Alpha 透明通道的高清表情贴纸；用户需要离开应用打开浏览器去搜图、抠图、存为 PNG，创作链路极长且繁琐；
2. **缺乏即取即用经典梗素材**：表情包二创的核心魅力在于经典元素的拼贴组合——例如“墨镜 Deal With It”、“红问号”、“流汗黄豆笑脸”、“好评/驳回印章”、“狗头贴脸”等。缺少这些素材，客户端空有图像叠加能力却缺乏“表情包灵魂”；
3. **画布交互缺乏尺寸缩放手柄**：当前画布仅能拖动位置，缩放必须在左侧侧边栏手动输入像素数字 `Width`，无法直接在画布上直观拉拽缩放，且画布上仅显示灰色“PNG”字样，缺少真实贴纸图像的所见即所得实时预览。

## 2. 竞品与业界方案调研

| 产品 | 贴纸库组织形式 | 画布交互与缩放 | 本地持久化与分发 |
|------|---------------|----------------|-----------------|
| Telegram Sticker / Editor | 底部抽屉分组网格，一键贴上画面 | 贴纸选中有四角旋转/缩放锚点 | 内置矢量/位图资源打包于客户端内 |
| 剪映 / CapCut 贴纸模块 | 侧边栏/抽屉素材库，分类 Tab（热门、搞笑、台词、遮挡） | 选框手柄（右下角拖拽缩放，整体拖拽移动） | 随安装包内置基础包，支持离线免配即用 |
| 各种在线 Meme Generator (Imgflip) | 常见贴纸快捷抽屉（墨镜、帽子、Scumbag 帽子等） | 点击即置入画布中心，支持手柄拉拽 | 云端 CDN 提供图片 URL |

## 3. 技术约束与决策依据

1. **资源存放与跨平台分发约束**：
   - FFmpeg 进行动图转码时，必须读取真实的本地文件路径（`image.path`）；
   - 前端 Webview 预览时，为了极速渲染、无网络依赖和避免本地路径跨域权限限制，需支持将内置贴纸转化为 Data URL 或通过 Tauri 协议读取；
   - 贴纸资源应包含在客户端打包产物内（`tauri.conf.json` 声明 `resources: ["stickers/*"]`），同时 Rust 端在初始化或调用时确保目标绝对路径可寻，做到免配即用。
2. **贴纸格式与透明度规范**：
   - 统一采用 8-bit RGBA 格式 PNG，分辨率 256×256 或 300×300，边缘平滑抗锯齿，背景严格透明；
   - 规范首批精选 18 款高频经典表情贴纸，分为三组类别（经典名场面、情绪表态、提示气泡）。
3. **画布交互设计约束**：
   - 画布内贴纸不仅支持鼠标整体拖拽平移，还在贴纸外框右下角提供显眼的缩放手柄（Resize Handle），拖拽手柄可实时按比例缩放贴图宽度 `imageWidth`；
   - 预览框内真正渲染对应透明贴纸的图像，彻底替换原本冷冰冰的“PNG”字符；
   - 贴纸库采用底部抽屉第 3 个 Tab（贴纸素材 🎨），侧边栏“03 叠加”模块提供一键直达“🎨 贴纸素材库”入口。
4. **性能与视口约束**：
   - 保持 1280×820 窗口零多余滚动条；
   - 18 张精选透明 PNG 总计仅约 150KB，零内存显存负担，不影响冷启动速度。
