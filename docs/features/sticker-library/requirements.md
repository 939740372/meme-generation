# 需求说明书：内置透明表情贴纸库 (sticker-library)

- 状态：ready-to-merge
- Feature slug: sticker-library
- 分支：feature/sticker-library
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 特性概述

在 Meme Studio 桌面客户端中内置开箱即用的透明 PNG 经典表情贴纸库，包含 18 款高频表情包二创核心素材（Deal With It 墨镜、红问号、流汗黄豆、狗头、好评/驳回印章、对话气泡等）。在抽屉中提供“贴纸素材”面板，支持分类浏览与一键置入画布；在中央预览画布中支持所见即所得图像渲染、鼠标独立平移拖拽，以及通过角手柄直观缩放大小。

## 2. 用户故事

1. **一键贴梗**：作为表情包创作者，我打开一个视频片段后，点击“贴纸库”，点击“墨镜”，墨镜立刻贴到画面中，无需我自己满世界去搜透明 PNG；
2. **直观排版**：我在中央画面中直接拖动墨镜到角色眼睛位置，拉动右下角缩放手柄放大/缩小，所见即所得；
3. **真实高质量导出**：点击导出 GIF/WebP，FFmpeg 将贴纸以正确透明度和尺寸合成进动图中；
4. **离线免配置**：无论是否联网，所有 18 款贴纸均内嵌于客户端，双击安装即用。

## 3. 功能需求 (FR)

- **FR-1 内置素材库准备**：
  - 精选内置 18 款高频透明 PNG 贴纸，放置于 `src-tauri/stickers/` 目录；
  - 覆盖三大分类：
    1. `classic` (经典梗图)：墨镜 (Deal With It)、红色黑人问号、连环问号 (???)、经典柴犬狗头、经典搞笑熊猫头、小丑红鼻子；
    2. `emotion` (情绪表态)：流汗笑脸 (流汗黄豆)、绝赞好评红印章、离谱驳回印章、暴青筋符号 (💢)、巨大汗滴 (💧)、金光闪闪 (✨)、桃心眼 (😍)、烈火燃烧 (🔥)、宽面条泪奔 (😭)、超赞大拇指 (👍)；
    3. `bubble` (对话提示)：尖角咆哮气泡、无语省略号气泡。
- **FR-2 Rust 资产定位与数据桥接**：
  - Rust 提供 `get_builtin_stickers` Tauri 命令；
  - 返回贴纸清单：`id, name, category, path, dataUrl`；
  - 能够自适应开发态与打包态（Resource 目录）解析贴纸绝对路径；
  - 返回 base64 dataUrl 确保前端无痛极速预览。
- **FR-3 抽屉贴纸库面板**：
  - 底部抽屉新增“贴纸素材 (🎨)”标签页；
  - 提供分类筛选药丸按钮（全部 / 经典梗图 / 情绪表态 / 对话提示）；
  - 网格卡片展示缩略图与贴纸名称，悬浮高亮；
  - 点击贴纸卡片即可将其应用至当前画布（自动勾选 `useImage`，载入对应绝对路径与预览图）。
- **FR-4 侧边栏快捷入口与控制**：
  - 侧边栏“03 叠加”的 PNG 图案栏新增“🎨 贴纸素材”按钮，点击直接唤起抽屉并切到贴纸选项卡；
  - 显示当前选中的贴纸名称与缩略图预览，支持一键移除或重选；
  - 增加预设快速缩放比率按钮（50%、100%、150%）。
- **FR-5 画布 WYSIWYG 渲染与交互手柄**：
  - 画布上不再显示冷冰冰的“PNG”字符，而是真实展示透明贴纸图像；
  - 点击或悬浮贴纸时显示亮色边界框与信息指示条；
  - 贴纸外框右下角显示缩放手柄（Resize Handle `⤡`），按住鼠标水平/垂直拉伸可平滑调整 `imageWidth`；
  - 贴纸内部区域按住鼠标可平滑平移 `imageX` 和 `imageY`。
- **FR-6 草稿与导出管线全兼容**：
  - 工作区自动草稿支持持久化贴纸路径与尺寸并在重启时无缝水合恢复；
  - 导出 GIF 与 WebP 管线通过 FFmpeg 滤镜正常叠加贴纸。

## 4. 非功能需求 (NFR)

- **性能**：贴纸总包体积 < 200KB，打开贴纸抽屉秒级渲染无卡顿；
- **跨平台**：路径构建使用规范 `PathBuf`，确保 macOS / Windows / Linux 路径均能正确被 FFmpeg 打开；
- **视觉一致性**：保持 Cyberpunk 霓虹深色调设计语言，固定在 `1280 × 820` 视口内，抽屉展开时零全屏多余滚动条。

## 5. 验收标准 (DoD)

1. `src-tauri/stickers/` 包含 18 款格式合规的透明 PNG 贴纸，且各贴纸元数据完整；
2. `get_builtin_stickers` 命令返回 18 条包含本地物理路径与 Data URL 的有效数据；
3. 点击侧边栏“🎨 贴纸素材”可展开抽屉，分类筛选与贴纸网格完整清晰显示；
4. 点击贴纸即可在中央画布中出现真实透明图案，点击并拖拽主体可移动位置，拖拽右下角手柄可平滑缩放尺寸；
5. 针对包含内置贴纸的工程，成功导出真实 GIF 与 WebP，确认合成效果正确；
6. `pnpm build`、`cargo check --locked`、`cargo test`、`git diff --check` 全部通过。
