# 视频导入与画面实时预览需求规范 (Requirements)

## 1. 目标与范围

为表情工坊桌面端构建完整的视频预览能力：让创作者在导入任意格式视频后，在主工作区画布中清晰看到视频的真实画面帧与片段动态循环预览，精准对照画面排版文字、贴纸与裁切框。

---

## 2. 用户故事 (User Stories)

1. **作为创作者**，导入一段短视频后，我希望能在中央画布里直接看到视频当前的画面，而不是只有黑色的抽象网格，以便我准确将台词贴在人物下方。
2. **作为创作者**，我调整截取时间段（如 `01.5s ~ 03.2s`）时，画布能实时更新对应时间点的帧画面，让我确认精彩表情出现的瞬间。
3. **作为创作者**，在导出动图前，我希望能在画布上点击“播放”，循环预览这 2 秒片段的动态效果，甚至查看滤镜调色后的实拍感觉。
4. **作为创作者**，当我导入 MKV 或 AVI 等特殊格式视频时，软件依然能够清晰呈现视频帧，不会因为浏览器无法直接播放而黑屏崩溃。

---

## 3. 功能需求 (Functional Requirements)

### FR-1：Rust 端极速单帧提取 API (`extract_video_frame`)
- 支持传入视频本地绝对路径、时间点（秒）及可选宽度限制（默认 640）；
- 调用内置 FFmpeg 快速精准定位单帧（`-ss` 预寻道），通过标准管道读取 JPEG 内存流转为 Data URL；
- 失败时返回标准化友好错误码，不遗留任何磁盘垃圾文件。

### FR-2：Tauri 2 本地资源协议支持 (`assetProtocol`)
- 在 `tauri.conf.json` 中配置安全作用域，支持在 Webview 中通过 `convertFileSrc` 播放本地 MP4 / MOV / WebM；
- 保证应用启动和跨平台打包安全性。

### FR-3：画布双模视频底图渲染
- 画布底层优先挂载真实视频流或高保真画面帧：
  - 静态/拖拽时：展示对应秒数的视频画面帧；
  - 动态预览时：展示 `<video>` 原生硬件加速播放；
- 特殊格式（如 MKV, AVI）原生播放失败时，自动降级为全时间轴高保真抽帧模式，界面友好提示。

### FR-4：片段循环播放与播放控制条
- 画布下方/上方集成轻量直观的预览控制器：
  - 播放 / 暂停切换（快捷键空格键支持）；
  - 选定区间 `[startSecs, endSecs]` 循环播放限制（播放到达 `endSecs` 时自动回滚到 `startSecs` 重新播放）；
  - 当前时间指针显示与拖动预览；
  - 播放速度自动联动（选用了 2x 鬼畜加速或 0.5x 慢速特效时同步视频倍速）；
  - 静音 / 开启原声音量控制。

### FR-5：裁切框、图层与滤镜实时所见即所得
- 开启裁切（Crop）时，九宫格裁切遮罩精准落在真实视频画面上方；
- 所有多图层文字（旋转、弧形、斜体、阴影、底框）与透明贴纸直接覆盖在视频画面之上；
- 视频滤镜（黑白、高反差、港风复古、反色负片等）通过 CSS filter 实时作用于视频/抽帧底图，预览效果与 FFmpeg 最终导出高度一致。

---

## 4. 非功能需求 (NFR)
- **响应速度**：单帧提取平均延迟不超过 50ms，拖动时间轴时有防抖保护（100ms），不卡死主线程；
- **稳定性**：内存无泄漏，单帧提取完成后立即释放子进程 pipe；
- **兼容性**：老版本草稿与各类视频尺寸（横屏、竖屏、方形、超宽屏）均可自适应等比居中缩放显示。
