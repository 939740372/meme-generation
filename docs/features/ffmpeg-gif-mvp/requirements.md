# 需求文档：FFmpeg GIF MVP

- 状态：researching
- Feature slug：ffmpeg-gif-mvp
- 分支：feature/ffmpeg-gif-mvp
- 负责人：待定
- 日期：2026-08-14

## 1. 目标

用户可以从本地视频选择一段内容，调整画面和输出参数，添加文字/图案，并导出一个可正常打开和播放的 GIF。

## 2. 范围

### 包含

- 选择本地视频并读取基础媒体信息；
- 设置起止时间；
- 设置裁切区域、输出宽度和帧率；
- 添加文字和 PNG 图案；
- 使用 FFmpeg 导出 GIF；
- 展示进度、成功结果、失败原因，并支持取消；
- 对输出文件进行存在性和基本可打开性验证。

### 不包含

- 云端上传、账号和素材市场；
- 多轨时间线和复杂图层动画；
- AI 生成或自动字幕；
- 批量处理；
- 第一版的音频处理和视频回导出。

## 3. 用户故事

- 作为内容创作者，我希望导入一段本地视频，从而快速制作一个 GIF。
- 作为内容创作者，我希望控制片段时长、画面范围、宽度和帧率，从而控制内容和文件大小。
- 作为内容创作者，我希望添加文字或图案，从而表达自己的梗和品牌。
- 作为内容创作者，我希望看到进度并能取消任务，从而避免被长时间卡住。

## 4. 功能需求

| 编号 | 需求 | 优先级 | 验收方式 |
| --- | --- | --- | --- |
| FR-01 | 选择视频并显示可用的基础媒体信息 | P0 | 导入正常短视频并核对信息 |
| FR-02 | 设置起止时间、裁切区域、宽度和帧率 | P0 | 使用不同参数导出并核对结果 |
| FR-03 | 添加文字叠加并设置位置、大小和颜色 | P0 | 输出画面出现对应文字 |
| FR-04 | 添加 PNG 图案并设置位置和大小 | P0 | 输出画面出现对应图案 |
| FR-05 | 通过 FFmpeg 导出 GIF，并验证输出文件 | P0 | GIF 存在、可打开、可播放 |
| FR-06 | 展示任务进度、完成、失败和取消状态 | P0 | 覆盖成功、失败和取消路径 |
| FR-07 | 对缺少 FFmpeg、输入无效和输出不可写给出错误 | P0 | 使用模拟或真实异常场景验证 |

## 5. 非功能需求

- 本地优先：默认不上传用户视频、图案或字体。
- 跨平台：核心参数和用户流程在 macOS、Windows、Linux 保持一致。
- 安全：文件路径和文本作为参数传递，不拼接未经校验的 shell 命令。
- 可恢复：失败和取消后清理临时文件，用户可以重新开始任务。
- 可重复：相同输入和参数产生可解释的结果，不静默覆盖用户文件。
- 可维护：FFmpeg 版本、构建来源和许可证记录在代码/文档中。

## 6. 错误和边界

- 输入文件损坏或格式不支持；
- 起止时间为空、倒置或超出媒体时长；
- 裁切区域越界或尺寸无法缩放；
- 文字字体缺失、图案路径不可读；
- FFmpeg sidecar 不存在、无法启动或返回非零退出码；
- 输出目录不可写、磁盘空间不足或目标文件已存在；
- 用户取消时 FFmpeg 未能及时退出。

## 7. 验收标准

- [ ] 能导入本地视频并显示基础信息。
- [ ] 输出片段的起止时间符合设置。
- [ ] 输出的尺寸、帧率和裁切区域符合设置。
- [ ] 文字和 PNG 图案在输出中位置、大小基本符合预览/设置。
- [ ] GIF 可以被系统或常用图片查看器打开并播放。
- [ ] 成功、失败、取消三种状态都能被用户识别。
- [ ] 异常输入或 sidecar 异常不会被误报为成功。
- [ ] 实际命令、环境和未覆盖项已记录在 implementation.md。

## 8. 未决问题

- 默认宽度、帧率和质量档位；
- 是否在 MVP 支持透明 GIF；
- 自定义字体文件和随应用分发字体的范围；
- 输出文件命名和覆盖策略。
