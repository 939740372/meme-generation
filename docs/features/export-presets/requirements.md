# 需求文档：导出预设与压缩质量控制

- 状态：ready-to-merge
- Feature slug: export-presets
- 分支：feature/export-presets
- 负责人：待定
- 日期：2026-10-22

## 1. 目标

在 Meme Studio 中引入**场景化导出预设**（微信表情 1MB、大表情 5MB、高清动图、轻量极速、自定义）与**调色板压缩质量等级控制**，使用户能够一键获得符合目标平台体积限制且画质最佳的 GIF。

## 2. 范围

### 包含
1. **预设列表定义**：
   - **微信标准表情**（`wechat-small`）：宽度 240px、帧率 10 FPS、压缩档位 `low`（有序抖动 `bayer:bayer_scale=3`，目标体积 < 1MB）；
   - **微信大表情**（`wechat-large`）：宽度 320px、帧率 12 FPS、压缩档位 `medium`（扩散抖动 `sierra2_4a`，目标体积 < 5MB）；
   - **高清社交分享**（`hd-social`）：宽度 480px、帧率 15 FPS、压缩档位 `high`（扩散抖动 `sierra2_4a`，高清画质）；
   - **轻量极速**（`lite`）：宽度 180px、帧率 8 FPS、压缩档位 `low`（极小体积，秒发）；
   - **自定义**（`custom`）：用户手动修改宽度、FPS 或压缩模式时自动激活。
2. **控制面板交互与状态联动**：
   - 在“输出”面板新增场景预设选择 Pills；
   - 点击预设按钮，参数输入框（宽度、帧率、质量）一键同步；
   - 手动改动数字输入框时，预设激活态自动切换为“自定义”；
   - 底部导出栏展示预设标签与预估体积说明。
3. **Rust 调色板压缩算法支持**：
   - `RenderPlan` 增加可选字段 `quality: Option<String>`；
   - 根据质量等级动态构建 `paletteuse` 滤镜的 `dither` 参数。
4. **保持 1280×820 窗口无滚动条**。

### 不包含
- 用户在本地保存命名自定义预设（后续模板功能覆盖）；
- WebP/AVIF 等非 GIF 格式预设（P3 阶段覆盖）。

## 3. 功能需求

| 编号 | 需求 | 优先级 | 验收方式 |
| --- | --- | --- | --- |
| FR-01 | 预设选择器 UI 与场景按钮 | P0 | 输出面板展示微信表情、大表情、高清、轻量、自定义按钮 |
| FR-02 | 点击预设一键修改输出参数 | P0 | 点击微信表情后，宽度自动为 240，帧率自动为 10 |
| FR-03 | 手动改动时自动更新为自定义 | P0 | 手动改动宽度为 300，激活状态自动跳到自定义 |
| FR-04 | 压缩质量等级与 dither 联动 | P0 | Rust 侧根据 quality 动态构建 bayer / sierra2_4a 调色板滤镜 |
| FR-05 | 导出真实体积对比验证 | P0 | 同一素材在微信表情预设下导出体积显著低于高清预设，且小于 1MB |
| FR-06 | 1280×820 窗口固定布局无溢出 | P0 | 预设控件嵌入后，无外层纵向/横向滚动条 |

## 4. 验收标准

- [x] 控制面板清晰呈现 4 个场景预设与 1 个自定义状态；
- [x] 切换预设后，宽度、FPS 与质量档位同步更新；
- [x] 手动输入数值后，选中的预设自动变为“自定义”；
- [x] 导出使用 `wechat-small` 预设生成的典型短视频 GIF，体积显著小于 1MB；
- [x] 导出使用 `hd-social` 预设生成的短视频 GIF，画面保持细腻且色彩平滑；
- [x] `1280×820` 固定视口下无任何滚动条；
