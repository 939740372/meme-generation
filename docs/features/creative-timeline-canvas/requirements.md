# 需求文档：可视化时间轴与画布拖拽创作工作区

- 状态：designed
- Feature slug：creative-timeline-canvas
- 分支：feature/creative-timeline-canvas
- 负责人：待定
- 日期：2026-10-22

## 1. 目标

在 Meme Studio 现有转码底座上，增加**可视化双向时间轴裁切滑块**与**中央预览画布内直接拖拽文字/PNG 贴图**的直观创作能力，实现所见即所得的表情包排版体验。

## 2. 范围

### 包含
1. **可视化时间轴组件**：
   - 支持拖拽左手柄调节片段开始时间（`startSecs`）；
   - 支持拖拽右手柄调节片段结束时间（`endSecs`）；
   - 中间高亮被选中的时间区间，并显示选区时长提示（如“已选 2.50s”）；
   - 与数值输入框双向实时同步；
   - 包含边界防交叉约束（`startSecs < endSecs`，最小间隔 0.1s，最大不超过视频总长）。
2. **画布所见即所得拖拽**：
   - 开启文字叠加时，画布上的文本可直接用鼠标点击并拖拽移动；
   - 开启 PNG 贴图时，画布上的贴图可直接用鼠标点击并拖拽移动；
   - 拖拽元素有明确的交互反馈（抓取光标、高亮选框、位置提示）；
   - 画面显示坐标与视频原始物理坐标系（`textX, textY, imageX, imageY`）进行实时精确双向映射；
   - 画布内拖拽即时同步控制面板数字输入框，控制面板改动即时反映在画布元素位置。
3. **保持 1280×820 固定视口约束**：
   - 新增的时间轴与交互元素无缝融入现有深色工业风工作区，无内外层滚动条。

### 不包含
- 多轨道复杂音频波形可视化（后置到 P3 阶段）；
- 旋转、斜切等复杂 2D/3D 变换。

## 3. 功能需求

| 编号 | 需求 | 优先级 | 验收方式 |
| --- | --- | --- | --- |
| FR-01 | 时间轴可视化轨道与双滑块手柄 | P0 | 导入视频后时间轴激活，显示起止滑块与高亮选区 |
| FR-02 | 拖动时间轴手柄实时更新起止秒数 | P0 | 拖动手柄时 `startSecs` 与 `endSecs` 同步变化且不交叉 |
| FR-03 | 时间轴与输入框双向联动 | P0 | 修改输入框，滑块位置实时更新；反之亦然 |
| FR-04 | 画布文字直接拖拽 | P0 | 开启文字后，在预览画面上按住文字可拖动到任意位置 |
| FR-05 | 画布贴图直接拖拽 | P0 | 导入 PNG 后，在预览画面上按住贴图可自由拖动 |
| FR-06 | 坐标精准缩放映射 | P0 | 画布拖拽坐标换算为视频原始物理分辨率坐标，保持 FFmpeg 导出位置一致 |
| FR-07 | 交互视觉提示 | P1 | 悬浮及抓取时的手势光标、虚线边框等反馈完整 |

## 4. 验收标准

- [ ] 导入视频后，时间轴能正确反映视频总时长；
- [ ] 拖拽时间轴左滑块和右滑块，开始/结束秒数实时变化，且始终保持 `startSecs < endSecs`；
- [ ] 在预览区直接拖动文本，控制面板中的 X / Y 坐标同步更新；
- [ ] 在预览区直接拖动贴图，控制面板中的 X / Y 坐标同步更新；
- [ ] 导出实际 GIF，验证文字与贴图在最终输出中的位置与画布上拖拽放置的位置一致；
- [ ] `1280×820` 窗口下整体界面完整，无水平与垂直滚动条；
- [ ] `pnpm build` 与 `cargo check` 正常通过。
