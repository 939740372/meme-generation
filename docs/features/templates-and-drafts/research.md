# 需求调研：常用表情包模板与草稿暂存

- 状态：ready-to-merge
- Feature slug: templates-and-drafts
- 分支：feature/templates-and-drafts
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 背景与核心痛点

当前 Meme Studio 已经具备了完整的媒体探测、时间裁切、矩形选框、文字描边/底框增强、动图双格式输出（GIF / WebP）以及导出历史记录能力。然而创作者在实际日常高频制作表情包的过程中，面临两大阻碍创作效率与安全感的明显痛点：

1. **未保存草稿意外丢失痛点**：
   - 创作者经常花费数分钟精细对齐台词时间轴、在画布中拖拽文字到关键人物嘴部、调整了描边与透明字幕框；若此时不小心误触快捷键关闭窗口、重启应用或系统崩溃，所有辛辛苦苦调整好的时间、裁切、样式、输入路径全部归零，产生极强的挫败感。
2. **经典表情包排版重复劳动痛点**：
   - 全网风靡的绝大多数 Meme 具备高度程式化、标准化的视觉排版范式，例如：
     - **“院线电影台词条”**：半透明黑底字幕条 + 居中白字微描边；
     - **“顶部大字吐槽带”**：画面上方粗黄字黑描边 + 吐槽文案；
     - **“名场面震撼大字报”**：画面中央大号粗体白字黑边，冲击力拉满；
   - 用户每次制作新表情包时，都需要从零反复调整文字 X/Y 坐标、字号、勾选描边、选描边颜色、开启底框、拉动透明度滑块……重复劳动繁琐低效。
3. **缺乏个人风格沉淀**：
   - 资深创作者往往有自己固定的一套设计参数（如个人水印贴图比例、固定字号和颜色），目前无法保存为自己的“专属模板”以便随时一键套用。

## 2. 用户与核心场景

- **场景 1：意外中断后的无缝恢复（草稿自动暂存）**
  用户正在调整一段 4 秒电影片段的经典台词，电脑突然电量耗尽或桌面窗口被意外关闭。重新打开客户端后，系统自动检测并恢复刚才的视频路径、截取时间区间、裁切框位置和打好的文字，弹出提示“已自动还原上次编辑草稿”，创作流程无缝衔接。
- **场景 2：一键套用经典排版模板**
  用户导入了一段新截取的沙雕视频，不想手动配参数，直接点击模板中的“经典影视字幕条”，文字样式、黑底字幕框与位置一键居中对齐，用户仅需修改台词文字即可立即导出。
- **场景 3：沉淀创作者个人模板**
  用户设计了一套非常满意的“粉红可爱描边 + 微信大表情尺寸”排版，点击“存为模板”，命名为“我的可爱专栏”。后续制作任何新表情包时，一键点击即可瞬间复用整套样式。

## 3. 技术调研与可行性分析

### 3.1 草稿暂存方案对比

| 存储方案 | 读写开销 | 复杂度 | 跨重启持久化 | 适用性分析 |
|---------|---------|--------|-------------|------------|
| **WebView localStorage + 防抖保存** | 极低（纯内存同步映射） | 简单清晰 | 是（WebKit/WebView2 本地隔离存储） | **最推荐**。草稿通常只有几十个字段（<5KB JSON），防抖 400ms 存入 localStorage 零卡顿且 100% 可靠。 |
| **Rust 写入本地磁盘 JSON 文件** | 需 Tauri IPC 异步交互 | 较高 | 是 | 适合数十 MB 的复杂工程，对于单页轻量草稿反而增加 IPC 负担和文件锁风险。 |

### 3.2 媒体文件可用性校验
- 当恢复草稿时，保存的 `inputPath` 本地视频文件可能已被用户移动或删除；
- 方案：恢复草稿时先调用 `probeMedia(draft.inputPath)`；若成功则无缝加载视频信息和预览；若失败（文件不存在），则优雅保留文字、裁切、样式等草稿配置，同时以轻量 Alert 提示用户“原视频文件已被移动，请重新选择视频源”，不发生白屏崩溃。

### 3.3 模板数据结构设计
模板分为两大类：
1. **预置内置模板 (Built-in Templates)**：系统内置 3 款精调参数的典型表情包排版，只读不可删除；
2. **自定义模板 (Custom Templates)**：用户随时从当前工作区“一键存为我的模板”，保存在 `localStorage`，支持命名、查看、删除。

## 4. 结论与决策

1. **自动草稿机制**：默认开启全自动实时草稿暂存（防抖 400ms），启动时若发现有效草稿自动静默恢复，并支持“清空/重置草稿”操作；
2. **内置 3 大经典模板**：
   - `经典影视字幕条`（底部半透明黑底框 + 白字细描边）
   - `顶部大字吐槽`（顶部居中 + 黄字粗黑描边）
   - `名场面大字报`（中央偏下 + 超大白字强对比描边）
3. **支持一键保存自定义模板**：在文字/排版区域提供“存为模板”按钮，支持自定义模板名称并在模板列表中统一管理；
4. **抽屉式模板管理中心**：抽屉面板整合为双视图（导出历史 / 模板库），保持桌面 `1280 × 820` 视口严整不产生整体滚动条。
