## 1. 特性概述

本特性为 Meme Studio 提供工作区**自动草稿暂存/恢复能力**与**表情包排版模板系统**。应用自动在本地暂存创作者当前未导出的编辑进度，防止误关或意外丢失；同时提供内置常见表情包预设排版（影视字幕条、顶部吐槽带、名场面大字报）和“一键存为我的模板”功能，大幅减少创作者的重复调参负担。

## 2. 用户故事

- **US-1 草稿自动恢复**：作为创作者，当我关闭桌面客户端后再次打开时，能够自动恢复上次正在编辑的视频、时间裁切区间、文字样式与参数，不需要从头再调一遍。
- **US-2 放弃/重置草稿**：作为创作者，当我想要重新开始一段全新创作时，可以一键“重置/清空草稿”，将工作区恢复到纯净初始状态。
- **US-3 快捷套用内置模板**：作为创作者，导入视频后，我可以在模板库中一键选择“经典影视字幕条”或“名场面大字报”，文字样式、描边和底框立即所见即所得生效，省去手动拖拽配置时间。
- **US-4 沉淀个人自定义模板**：作为创作者，在精调好一套满意的表情包排版后，我能够点击“存为模板”，输入名称保存，并在未来的任何新视频上一键复用。
- **US-5 模板列表管理**：作为创作者，我在抽屉或侧边栏可以浏览所有内置与自定义模板，并能删除不再需要的自定义模板。

## 3. 功能需求清单

### 3.1 自动草稿机制
- **FR-1 自动持久化**：创作者对视频源、时间轴、裁切框、文字叠加、图案贴图、预设质量、导出格式的任何修改，均在防抖 400ms 后自动序列化并存储至本地持久层 `meme_studio_active_draft`。
- **FR-2 启动自动恢复与容错**：应用初始化时读取草稿：
  - 若包含 `inputPath` 且文件存在，调用 `probeMedia` 恢复媒体信息，还原全部编辑参数，并弹出轻提示“已恢复上次未完成的草稿”；
  - 若视频源文件已被移动或不存在，保留排版参数与文字内容，温和提示创作者视频源不可用；
  - 若无草稿，保持默认空初始状态。
- **FR-3 重置草稿能力**：在工作区或顶部提供“清空/重置”动作，清空本地草稿并重置所有响应式状态。

### 3.2 经典与自定义模板系统
- **FR-4 3 款内置官方模板**：
  1. **经典影视字幕条**：
     - 文字：白字 `#ffffff`，字号 `26px`，描边 `2px` 纯黑，开启半透明黑底字幕条（透明度 `0.65`），位置居中偏下；
  2. **顶部大字吐槽**：
     - 文字：金黄 `#ffe600`，字号 `32px`，描边 `3px` 纯黑，关闭底框，位置居中偏上；
  3. **名场面震撼大字报**：
     - 文字：白字 `#ffffff`，字号 `44px`，描边 `4px` 纯黑，关闭底框，位置中央偏下，视觉冲击力极强。
- **FR-5 一键存为我的模板**：
  - 文字叠加区域提供“存为模板”按钮；
  - 支持弹出输入弹窗或快速命名，将当前文字样式（字号、颜色、描边宽/色、底框/底色/透明度、相对位置等）保存至 `meme_studio_custom_templates`。
- **FR-6 模板库列表与抽屉整合**：
  - 侧边栏/底部抽屉新增“模板库”分类或选项卡（内置模板 + 我的自定义模板）；
  - 单击卡片即可将排版一键应用到当前画布中（保留当前视频与已输入的文字文案，若文字为空则填入模板默认示例文案）；
  - 自定义模板支持删除。

## 4. 非功能需求

- **NFR-1 性能与稳定性**：草稿自动存储必须采用防抖（Debounce）设计，禁止在高频拖拽手柄时引发同步性能开销；
- **NFR-2 界面空间守恒**：抽屉与控制面板严格保持在 `1280 × 820` 固定视口内，不引发外层容器滚动；
- **NFR-3 向后兼容**：模板与草稿数据结构带有版本标记（如 `version: 1`），遇到无法解析的历史坏数据时自动捕获异常并降级重置，绝不导致应用白屏。

## 5. 验收标准 (Acceptance Criteria)

1. **AC-1**：导入视频并修改时间、文字和裁切参数后，刷新页面或重启客户端，所有状态完整还原并伴有轻量恢复提示。
2. **AC-2**：点击“经典影视字幕条”模板，文字立即变为带有半透明黑底框的居中字幕条，预览画布所见即所得。
3. **AC-3**：点击“存为模板”，输入名称后可在模板列表中成功查看，并能在导入其他视频时一键套用该模板参数。
4. **AC-4**：自定义模板支持从列表中删除，内置模板受保护不可删除。
5. **AC-5**：全量代码通过 `pnpm build`、`cargo check`、`cargo test` 与 `git diff --check`。
