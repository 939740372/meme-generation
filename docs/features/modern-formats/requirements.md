# 需求说明书：现代小体积动图 WebP 格式支持

- 状态：ready-to-merge
- Feature slug: modern-formats
- 分支：feature/modern-formats
- 负责人：Antigravity
- 日期：2026-10-22

## 1. 特性概述

本特性为 Meme Studio 引入现代动图格式 —— **WebP（Animated WebP）** 导出能力。用户可以在导出面板中在经典的 GIF 格式与现代 WebP 格式之间自由切换。WebP 模式下跳过耗时的调色板分析计算，以极高的压缩效率直接输出真彩色高帧率动图，且全链路在历史记录、缩略图预览、剪贴板复制和访达定位中顺畅流转。

## 2. 用户故事

- **US-1 格式选择**：作为创作者，我在导出参数面板中能够看到格式选择控件（GIF / WebP），点击切换时能直观了解 WebP 的优势（高压缩比、真彩色、更快速）。
- **US-2 路径自动联动**：作为创作者，当我从 GIF 切换为 WebP 时，默认或已填写的输出路径后缀自动由 `.gif` 变更为 `.webp`，无需我手动逐字修改文件名。
- **US-3 快速导出**：作为创作者，在选择 WebP 格式导出时，FFmpeg 不会卡在调色板生成阶段，整个渲染过程平滑快捷，并产出体积明显更小的动图文件。
- **US-4 历史记录与管理**：作为创作者，在最近导出列表与历史记录抽屉中，我能够清晰看到文件是 GIF 还是 WEBP，并且 WebP 动图能够正常播放动画缩略图、一键在访达中定位或复制到剪贴板。

## 3. 功能需求清单

### 3.1 前端界面与交互
- **FR-1 格式切换药丸控件**：
  在输出保存区域或控制面板顶部提供优雅紧凑的分段式按钮（Segmented Pill）：
  - `GIF`（附带“经典兼容”）
  - `WebP`（附带“推荐/小体积”）
- **FR-2 文件名与保存对话框联动**：
  - 切换格式后，如果当前路径以旧后缀结尾，自动替换为新后缀；
  - 点击“浏览/选择保存位置”打开系统保存对话框时，默认文件类型与格式选框根据当前选定格式自动匹配（`.gif` 或 `.webp`）。
- **FR-3 历史卡片与标识**：
  - 历史卡片文件名右侧增加格式药丸标识（`GIF` 灰色风格 / `WEBP` 蓝紫高光风格）；
  - 载入历史记录参数时，能够自动还原当时的导出格式（GIF 或 WebP）。

### 3.2 Rust / 后端能力
- **FR-4 导出计划结构扩展**：
  - `RenderPlan` 新增 `format: Option<String>`，允许传递 `"gif"` 或 `"webp"`；
  - 增加 `is_webp(&self) -> bool` 判定逻辑，若未显式指定 `format` 则根据 `output_path` 的扩展名自动兼容推断。
- **FR-5 输出路径校验扩展**：
  - 放宽 `validate_render_plan`：合法扩展名扩展为 `.gif` 与 `.webp`；
  - 校验格式配置与文件扩展名的一致性。
- **FR-6 FFmpeg 滤镜图与转码指令定制**：
  - 当为 WebP 时：
    - 滤镜图终点直接以 `[vout]` 输出，跳过 `split`、`palettegen` 和 `paletteuse` 滤镜；
    - 编码参数追加 `-c:v libwebp -loop 0`；
    - 映射质量参数 `-q:v`（如 low: 55, medium: 75, high: 90）；
    - 输出参数不强制 `-f gif`。
  - 当为 GIF 时：
    - 完整保留既有的调色板生成与抖动算法管线，保持 100% 既有表现稳定。

## 4. 非功能需求

- **NFR-1 视口无溢出**：新控件紧凑融合进控制面板，严守 `1280 × 820` 固定视口，绝不引发页面外层出现滚动条。
- **NFR-2 性能保证**：WebP 模式下渲染转码时间相比 GIF 格式降低 40% 以上，且导出的 WebP 动图具备正确的循环播放参数（`-loop 0` 无限循环）。
- **NFR-3 兼容性**：不破坏既有全部 GIF 功能，向后兼容未传递 `format` 的旧数据结构。

## 5. 验收标准 (Acceptance Criteria)

1. **AC-1**：用户可以在界面上自由切换导出格式为 `GIF` 或 `WebP`，切换后保存路径后缀自动同步变化。
2. **AC-2**：选择 WebP 格式点击导出，转码成功并在磁盘生成合法的 `.webp` 动图，在 Chrome/Safari 等现代环境及系统预览中可流畅循环播放。
3. **AC-3**：相同视频片段、相同尺寸与帧率下，WebP 格式文件的字节体积显著小于 GIF 格式。
4. **AC-4**：导出的 WebP 文件在右侧历史卡片与底部滑出抽屉中均可正确播放动图预览，展示 `WEBP` 格式徽标，并支持在访达中打开与复制到剪贴板。
5. **AC-5**：全量前端构建、Rust 语法检查、Rust 单元测试全部通过无报错。
